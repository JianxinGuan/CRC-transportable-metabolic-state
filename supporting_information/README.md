# Supporting Information formats

Both PDF and PNG versions of Supporting Figures S1-S3 are intentionally retained.

- PDF files preserve vector elements for scientific review, printing, and production workflows.
- PNG files provide immediately viewable raster previews and match the journal-upload figure set.
- The paired formats contain the same scientific panels and are not independent analyses.
- `tables/S1_Table.xlsx` is the consolidated Supporting Information workbook.

All seven Supporting Information files were compared by SHA-256 with the current journal-upload directory before the clean public-release history was created.
