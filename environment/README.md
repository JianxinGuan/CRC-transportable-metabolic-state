# Software environment records

The `sessionInfo_*.txt` files were captured from the principal analysis and figure-generation stages. They are retained separately because the analyses were completed at different times and may have loaded different package subsets.

Before the public v1.0.0 release:

1. map each session file to its generating script;
2. consolidate core package versions into a human-readable table;
3. test the documented entry points in a clean environment;
4. record the operating system and external resources required for oncoPredict and structural analyses.
