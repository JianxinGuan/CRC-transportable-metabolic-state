# Provenance-only archive

Files under `provenance_only_scripts/` are retained to document historical analysis provenance. They are not part of the supported execution path, have not all been parameterized for the public directory layout, and have not all passed clean-environment numerical testing.

Do not interpret their presence as an end-to-end reproducibility claim. The supported scripts are listed in `metadata/script_inventory.tsv` and reside under the top-level `scripts/` directory.
